# Parallel Financial News Event Detection and Temporal Relation Extraction

## Overview

This project implements a complete NLP pipeline for detecting financial events and extracting temporal relations from financial news using FinBERT.

## Features

* Financial Event Detection
* Temporal Relation Classification
* Cross-Sentence Event Linking
* Parallel NLP Preprocessing

## Technologies

* Python
* PyTorch
* HuggingFace Transformers
* FinBERT
* spaCy
* Parallel Processing

## Results

* Event Detection Accuracy: **87.86%**
* Temporal Relation Accuracy: **70.75%**
* Parallel Speedup: **1.47x**

* `pipeline.ipynb` — Complete implementation
